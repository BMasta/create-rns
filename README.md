**Create: Rock & Stone** aims to close the gap between Create and traditional factory game experience by bringing infinite mineable resource deposits into the world.
Make your own massive drill and cash in on the bounties of nature!
![](gallery/main_screenshot.png)

## How do I change how often deposits spawn in the world?
Create: Rock & Stone ships with pre-existing datapacks to tweak deposit worldgen, including one to disable deposit generation completely.

### New world
Datapacks can be added to a new world in a world creation screen. 

### Existing world
In an existing world, run `/datapack list` to see available datapacks and `/datapack enable "<datapack>"` to enable one. This will stop the generation of new deposits, but existing deposits will be untouched.

## What can I tweak?
* Add new custom deposits
* Change mined resources for existing deposits (mining recipe)
* Change mining speed
* Change Size of claimable area
* Add custom resonators, overclocks, and other catalysts
* Change existing catalysts
* Change spawn frequency of deposits (more granular than using a pre-existing datapack)
* Max scanning distance

All of the above can be tweaked with KubeJS (or a plain datapack).
